Apagar tudo e recomeçar

Apaga a referência do ano vigente (passo 1), o ciclo atual (base do passo 3, já processada) e todas as edições/turmas pendentes de todas as marcas (Regras, Exceções, Novas turmas). Não apaga o histórico de ciclos anteriores já arquivados. Use isso quando quiser subir os passos 1 e 3 do zero.

7. Diretores e configuração do ano seguinte

Fluxo para preparar um novo ano de adoção:
1. Envie a lista de adoção completa do ano vigente (com Selo/Coleção) — ela é a referência.
2. (Opcional) Cadastre Selos/Coleções que ainda não existem na base atual, mas que os diretores vão poder escolher para o ano seguinte.
3. Envie a lista de turmas do ano seguinte (só Marca/Unidade/Turma/Turno) — o sistema calcula a regra inicial de cada turma a partir da referência do passo 1, e o que não tiver referência vai para "Novas turmas".
4. Sempre que a lista de turmas for atualizada durante o ano, envie o arquivo de novo no passo 3 — o sistema reconhece o que já existe e só processa as turmas novas, sem apagar nada do que já foi feito.

1. Lista de adoção do ano vigente (referência)

Suba aqui a lista de adoção completa e atual (Marca, Unidade, Turma, Turno, Selo, Coleção, Utilização) — é usada só como referência para calcular as regras do ano seguinte no passo 3, não altera o que está sendo editado agora.

2. Selos e Coleções novos para o ano seguinte

Suba aqui uma planilha com as colunas Selo, Coleção para cadastrar materiais que ainda não existem na lista de adoção atual, mas que devem aparecer como opção para os diretores escolherem no ano seguinte.

3. Lista de turmas do ano seguinte

Suba aqui o arquivo com as turmas do ano seguinte (Marca, Unidade, Turma, Turno — sem Selo/Coleção). A ferramenta calcula a regra inicial de cada turma assim: 1) se a mesma Marca+Unidade+Turma+Turno já existia na referência do passo 1, usa o mesmo material; 2) se não existia, usa o material mais frequente entre outras unidades da mesma Marca+Turma+Turno; 3) se não há nenhuma referência, a turma vai para "3. Novas turmas" para o diretor preencher manualmente. Se já existir um ciclo em andamento para o mesmo ano alvo, o envio é incremental — só as turmas novas do arquivo são processadas; o que já existe não é alterado.
